# Text Case Converter

A terminal tool for converting text to common naming and display styles, including camel case, snake case, kebab case, title case, sentence case, and alternating case.

## Run it

```powershell
uv sync
uv run python main.py
```

Choose a format, enter text, and the converted value is printed to the terminal. Choose `A` to print every available conversion for the same input.

## Dependencies

- Python 3.14+
- No third-party packages
