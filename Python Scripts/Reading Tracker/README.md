# Reading Tracker

A local Streamlit dashboard for managing a reading list, progress, ratings, notes, and reading statistics.

## Setup

```powershell
uv sync --no-config
```

## Run

```powershell
uv run --no-config streamlit run main.py
```

Books are stored in `books.json` beside `main.py` after the first save. Treat it as personal reading data and do not commit it. The app runs locally and makes no network requests.
