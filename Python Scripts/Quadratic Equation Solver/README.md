# Quadratic Equation Solver

An interactive terminal calculator for linear, quadratic, and cubic equations.

## Setup

```powershell
uv sync --no-config
```

## Run

```powershell
uv run --no-config python main.py
```

Use the menu to solve equations, inspect quadratic discriminants and vertices, draw an ASCII parabola, or evaluate a polynomial at a chosen value.

## Notes

The tool supports complex roots and uses numerical formatting for display. Cubic roots can carry small floating-point differences. It runs locally with the Python standard library and makes no network requests.
