# Base64 Encoder Decoder

Encode or decode text and files with standard Base64, URL-safe Base64, Base32,
or Base85 using only the Python standard library.

```powershell
cd "Python Scripts/Base64 Encoder Decoder"
uv sync
uv run python main.py
```

The interactive menu supports text, file encoding, decoding, and scanning text
for Base64 candidates. Base64 is encoding, not encryption; do not treat it as
protection for sensitive data.
