# Random Color Palette Generator

A local Streamlit tool for creating random and color-harmony palettes.

## Setup

```powershell
uv sync --no-config
```

## Run

```powershell
uv run --no-config streamlit run main.py
```

Choose a generation mode, select a base color where relevant, and copy the displayed hex values. The app runs locally, creates no files, and makes no network requests.
