# Insurance Estimator

A local Streamlit learning demo that fits small regression models to synthetic health and auto-insurance data. Its outputs are illustrative only: they are not quotations, underwriting decisions, or financial advice.

## Run

```powershell
uv sync --no-config
uv run --no-config streamlit run main.py
```

All data is generated deterministically within the app. Nothing is uploaded, saved, or sent to an insurer.
