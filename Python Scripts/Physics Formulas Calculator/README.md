# Physics Formulas Calculator

An interactive terminal calculator for common introductory physics formulas.

## Setup

```powershell
uv sync --no-config
```

## Run

```powershell
uv run --no-config python main.py
```

Choose a menu section for kinematics, forces, energy and power, waves, the ideal gas law, electrical circuits, or physical constants. Leave the unknown value blank in the SUVAT and ideal-gas-law prompts when the selected formula can solve for it.

## Notes

The calculator uses SI units and runs locally with only the Python standard library. It does not read files or make network requests.

This is an educational calculator. Check assumptions, sign conventions, units, and model applicability before using a result in real-world work.
