# Fraud Detection Demo

Streamlit demonstration of transparent, rule-based transaction risk scoring over synthetic data.

## Run

```powershell
uv sync --no-config
uv run --no-config streamlit run main.py
```

## Scope

- The transaction feed is generated in memory; it does not load, store, or send real transaction data.
- The rules and score thresholds are illustrative only.
- Do not use the output to approve, decline, investigate, or otherwise make decisions about real people or transactions.
- “Demo stats” compare scores with labels generated by the same simulation. They are not independent model-validation results.

Requires Python 3.13 or later, pandas, and Streamlit.
