# Username Generator

A local terminal tool for generating username ideas from a name, keyword, or random word combinations. It can filter suggestions by length and allowed characters.

## Run it

```powershell
uv sync
uv run python main.py
```

Choose a generation mode from the menu. The tool creates suggestions only; it does not check whether a name is available on any service.

## Dependencies

- Python 3.14+
- No third-party packages
