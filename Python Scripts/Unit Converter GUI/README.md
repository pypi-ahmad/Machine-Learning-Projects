# Unit Converter GUI

A Tkinter desktop converter for length, weight, temperature, volume, area, speed, time, and data units. Select a category, source unit, destination unit, and value to see the converted result and a table of related values.

## Run it

```powershell
uv sync
uv run python main.py
```

The app opens a local desktop window. Use the Swap button to exchange the source and destination units.

## Dependencies

- Python 3.14+
- Tkinter, included with standard Windows Python installations
