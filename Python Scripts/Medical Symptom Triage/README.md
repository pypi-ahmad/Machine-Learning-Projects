# Medical Symptom Triage

An educational Streamlit demonstration of simple rule-based urgency triage. It is not a diagnosis system, medical advice, or a substitute for emergency services or a qualified clinician.

```powershell
uv sync --no-config
uv run --no-config streamlit run main.py
```

For severe, sudden, or life-threatening symptoms, seek emergency care immediately. The app runs locally and does not send symptom selections to an external service.
