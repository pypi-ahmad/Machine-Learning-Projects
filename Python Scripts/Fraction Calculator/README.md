# Fraction Calculator

Interactive command-line calculator for exact fraction arithmetic, mixed-number display, continued fractions, and rational approximations.

## Run

```powershell
uv sync --no-config
uv run --no-config python main.py
```

## Input

- Enter fractions such as `3/4`, `-5/8`, or mixed numbers such as `1 2/3`.
- Decimal conversion accepts finite numeric values only.
- The best-rational tool requires a positive maximum denominator.

The calculator uses only the Python standard library and requires Python 3.13 or later.
