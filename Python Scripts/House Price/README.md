# House Price Demo

Synthetic Streamlit demonstration of an OLS house-price estimator.

```powershell
uv sync --no-config
uv run --no-config streamlit run main.py
```

The training records, estimates, confidence range, and metrics are illustrative only. Do not use them for lending, appraisal, purchase, sale, tenancy, or other housing decisions. Requires Python 3.13 or later, pandas, and Streamlit.
